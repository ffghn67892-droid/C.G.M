# B단계 결과 — 렌더러 경계와 중복 구현 정리

작성: 2026-09-18 KST  
상태: 완료. 다음 단계(C) 시작은 별도 사용자 승인이 필요하다.

## 범위와 결과

- `tests/harness.cjs`를 공통 VM/DOM 하네스로 확정하고 `tests/daily-quests.test.cjs`의 복제 하네스를 제거했다.
- 같은 이름의 함수가 뒤 파일에서 다시 정의되어 동작이 바뀌던 경로를 정리했다. 기존 구현은 `renderLegacy…`, `syncLegacy…` 이름으로 보존하고, 최종 호출 경로는 한 번만 정의했다.
- `manager.js`를 현행 패키지 목록 안의 렌더러 단일 초기화 진입점으로 만들었다. 의존성 확인, 초기화, 타이머, 복귀 구독, 화면 갱신을 이 경계에서 시작한다.
- 스냅·마이트앤매직·탭 렌더링의 최종 구현 이름을 명시하고, 기존 이벤트 처리와의 호환용 얇은 호출 함수를 한 번만 두었다.

변경 파일은 `app.js`, `game-config.js`, `manager.js`, `mission-updates.js`, `overview.js`, `setup.js`, `tests/daily-quests.test.cjs`, `tests/harness.cjs`다. 게임 규칙, 보상, 저장 스키마(v2), 저장 키, 화면 배치와 설치 관련 파일은 변경하지 않았다.

별도 `renderer-entry.js`는 추가하지 않았다. 이 파일은 현재 패키지 파일 목록에 포함되지 않으며, 사용자는 설치 관련 파일 작업을 중단하도록 지시했다. 이관이 필요하면 설치 설정 변경을 별도 승인받아 진행한다.

## 검증

- 수정 JavaScript 6개 파일의 `node --check` 통과.
- `npm.cmd test`: 58개 중 58개 통과.
- 소스 Electron 스모크: preload 격리, 저장 후 재로드, 트레이 최소화와 일반 종료를 확인해 통과.

설치본 빌드·검증은 수행하지 않았다. 이는 현행 작업 원칙과 사용자 지시에 따른 제외 범위다.
